笔记本发送前将本机目标固化为 `book_sent:<taskId>`；operation_id 重试复用 sent，后继修改有独立 seq。目录 / 元数据 ACK 分轨处理，pull 不假 ACK；409 保留本机目标与历史，人工选择后重新基线并生成新 operation。引用依赖、循环和未同步内容保护集中在 Repository。

格式 3 导入不覆写同 ID 当前正文，不同备份正文进入历史。图片先准备，数据库在一次事务内提交；持久化附件 receipt 可重试。图片缓存上限与 ZIP 实际解压总量均为 128 MiB，分享每次最多 10 张、单张 10 MiB；缓存达到上限继续在线返回 / 上传，不删除未同步内容。偏好实际使用 SharedPreferences，令牌使用单独的 Keystore 加密文件。

## 性能与最终产物

性能使用非 debuggable、release R8 / 资源压缩、profileable 目标应用，独立 debug 签名 `.benchmark` 包；测量模块可调试。`CompilationMode.None` / run-from-apk，冷启动各 10 轮；仅本机缓存，未接入后端，模拟器网络保持开启。500 条元数据，正文样本实际 1,760 字符（场景名保留初始约 2,000 字符目标），不是 5,000 / 20,000 条大库测量。

| 场景 | 指标 | 中位数 | P95 |
| --- | --- | --- | --- |
| 500 条本机笔记 | 首帧 | 624.110 ms | 764.306 ms |
| 500 条本机笔记 | 列表加载完成 | 971.223 ms | 1,111.983 ms |
| 已缓存普通笔记 | 首帧 | 555.255 ms | 670.224 ms |
| 已缓存普通笔记 | 编辑器准备完成 | 1,729.039 ms | 1,911.770 ms |

P95 使用 nearest-rank：`ceil(0.95 × n)`，10 轮时等于最大样本，没有删除慢样本。全部轮次与设备上下文保存在 [performance-2026-11-20.json](performance-2026-11-20.json)。列表首次 trace 结束过早导致工具无法找到 fully-drawn 后的帧，等待列表与界面 idle 后只复核列表并通过；笔记场景首次 10 轮通过，不重复采样。模拟器列表 P95 略超初始 1 秒目标，此处保留结果；真机列表 / 笔记预算、温度与耗电仍需实测，不能以模拟器数据宣布达标。
