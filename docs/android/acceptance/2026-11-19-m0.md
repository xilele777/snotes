运行期间修正了 Windows properties 路径转义、debug domain 的显式 includeSubdomains、release 资源压缩、单色图标和 Compose v2 测试入口。TypeScript 契约消费测试归于 tests/unit，避免让 Worker 类型检查依赖前端 raw 资源模块。

完整 test:all 后仅移动同一 TypeScript 消费测试到 tests/unit；移动后再次执行该文件的 57 个测试及 npm run build，均通过。

### 复现命令

```powershell
.\android\gradlew.bat -p android :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:connectedDebugAndroidTest --console plain
.\android\gradlew.bat -p android :app:assembleRelease :app:lintRelease --console plain
npx vitest run tests/unit/android-contract.test.ts
npm run test:all
npm run build
```

本机 Java 网络请求通过单次 `-Dhttp(s).proxyHost / proxyPort` 参数接入已存在代理。校验最后一次 debug 资源更名时使用 `--no-watch-fs --no-build-cache` 排除旧缓存；最终 Debug 验证整轮通过。代理与 SDK 路径没有写入受版本控制的配置。
