# M3 服务端同步自动验收

[实施计划](../implementation-plan.md) · [同步契约](../sync-contract.md)

日期：2026-11-20（Asia/Shanghai）。M3 核心同步已实现，隔离 Node / Worker 联通与故障测试通过；继续进入 M4。人工 Web / Android 界面互编、真机输入与实际后台调度留在后续人工验收清单。

## 实现

- Retrofit 3.0.0 / OkHttp 4.12.0，固定实例 origin、Bearer、拒绝重定向、15 秒请求总超时、取消传播、必需端点探测、严格整数 / 正文校验。日志不记录令牌、请求正文或服务端错误原文。
- Android Keystore AES-GCM 加密连接配置，profile AAD 与原子文件写入；密钥丢失保留密文与离线库，允许修复令牌。401 持久化 `requires_auth`，修复前停止网络同步。
- `SyncCoordinator` 单轮锁与独立生命周期，多个调用合并；调用方退出不提前释放锁，停止后等待在途请求及 ACK 收尾。
- 两域 checkpoint、`pending_epoch`、`reconcile_notes` / `reconcile_books`、上传 epoch 围栏。库存末尾验证当前水位，接纳 epoch 前复查两域与实例。
- 普通元数据分页、分组、50 篇正文批次 / 最多 3 并发；缺项不把正文当空串，不推进游标。Room 事务与编辑器 stage 共用 monitor，重新检查 outbox、文件草稿与活跃编辑器。
- 同实体因果链、分组先于引用笔记、发送前重新读取 seq / 基线、最多 3 条上传链；发出请求前保存不可变快照。ACK 按实际接受轨道推进，旧响应与旧失败不消费新输入。
- 成功正文冲突先原子生成可追溯恢复副本，再消费任务。create replay 拉取真实服务端内容；404 / 413 等永久失败保留任务，可重试、另存与导出；410 保留未确认非空正文后清理旧身份。
- 全量库存只清点开始前的身份，保留未确认 create 与清点中新建，失踪正文保存恢复副本。笔记本独立时钟、两种分页结束条件、目录合法性与引用状态校验。

Room schema 仍为 1：笔记本的完整原始只读投影与版本保存在 `sync_meta` 的 `book:<id>`，现有 book / toc 表负责索引与列表，不丢弃原协议字段。发送快照与恢复状态也保存在该表；没有 destructive migration。

## 复现

```powershell
.\android\gradlew.bat -p android :app:testDebugUnitTest :app:connectedDebugAndroidTest :app:lintDebug :app:assembleDebug :app:assembleRelease --console plain
npx vitest run tests/unit/android-contract.test.ts

# 隔离 Node 测试入口，另一个终端保持运行
npx esbuild android/scripts/m3-node.ts --bundle --platform=node --format=esm --packages=external --outfile=android/app/build/m3-node.mjs
node android/app/build/m3-node.mjs

# 隔离 Worker：只使用本地数据库，另一个终端保持 dev 运行
npx wrangler d1 migrations apply android-m3-test --local --config android/scripts/wrangler.m3.jsonc --persist-to android/app/build/m3-worker-state
npx wrangler dev --local --config android/scripts/wrangler.m3.jsonc --persist-to android/app/build/m3-worker-state

# 安装 Debug 与 androidTest APK 后，分别执行两个后端用例
adb -s emulator-5580 shell am instrument -w -e class io.github.xilele777.snotes.core.BackendSyncTest -e m3Backend node io.github.xilele777.snotes.debug.test/androidx.test.runner.AndroidJUnitRunner
adb -s emulator-5580 shell am instrument -w -e class io.github.xilele777.snotes.core.BackendSyncTest -e m3Backend worker io.github.xilele777.snotes.debug.test/androidx.test.runner.AndroidJUnitRunner
.\android\scripts\verify-sync-ack-recovery.ps1 -AdbPath <adb路径> -Backend node
.\android\scripts\verify-sync-ack-recovery.ps1 -AdbPath <adb路径> -Backend worker
```

真实后端测试与进程夹具从普通 connected 任务排除，只由显式命令驱动。端口固定为 18787 / 18788，使用公开的测试专用 token；测试入口不被生产构建导入。恢复控制只修改 `android/app/build/` 下的隔离数据库，未接触生产账号或生产数据库。

M3 只接入手动同步；WorkManager、图片编辑会话插入、完整导航和实例切换在 M4 实施。单轮并发调用已验证，但尚不以它代替真实 Worker / Doze 验收。未捕获或未落盘的最后一次输入依旧有窗口；没有宣称普通 PATCH exactly-once 或最后一个字绝不丢失。
