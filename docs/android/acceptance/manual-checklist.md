# Android 内部包人工验收清单

日期：2026-11-20。适用：snotes 1.1.5 内部包，versionCode 2，包名 `io.github.xilele777.snotes.debug`。此清单未执行项保持未勾选；[自动验收记录](2026-11-20-m4-m6.md) 单独记录工程证据。安装包及 ZIP 位于仓库 `artifacts/android/`，包中提供 manifest、SHA-256 与本清单副本。

## 安装与接入

- [ ] 在真机允许本次安装来源，安装 APK，确认可离线新建并重新打开；debug 包与正式应用可并存。
- [ ] 记录机型、Android、WebView、输入法版本和电池策略；至少覆盖 API 26 / 较低系统、当前主流系统及一台省电限制明显的设备。
- [ ] 使用自己的 HTTPS 实例与 Owner 令牌接入，同步普通笔记和笔记本。正文未下载应提示不可编辑，不能显示成空正文。
- [ ] 修复失效令牌；确认离线内容与待同步任务保留。更换 origin 后出现独立空间，设置切回旧空间不会串数据。
- [ ] 同签名旧内部包覆盖升级，确认实际草稿、outbox、checkpoint 和缓存图片保留。请先导出备份；本包不能覆盖不同签名的安装。

## 写作与阅读

- [ ] 常用中文输入法和系统输入法：拼音候选、组合输入、换行、删除、emoji、光标、选择 / 撤销；最后一次输入后立刻返回或切后台，重新打开核对文字。
- [ ] 短文源码 / 阅读切换、工具栏、链接、图片、列表、任务、代码、表格和空行正常；IR 仅试用，源码 + 预览为默认路线。
- [ ] 连续输入后旋转、切笔记、后台返回；确认文字、保存状态与文档对应，没有旧 ACK 改写新文档。
- [ ] 约 76,000 字符长文在源码模式打开、输入和保存，记录耗时；不要以短文 IR 结果推断长文性能。
- [ ] 系统字体放大、小屏、横屏、键盘与预测性返回：主要按钮可达，键盘不遮住编辑位置；TalkBack 可读名称与状态、可完成导航和编辑。
- [ ] 搜索、筛选、分页位置、星标、置顶、分组、回收站预览 / 恢复、草稿另存和正文历史恢复正常。

## 同步与数据管理

- [ ] 飞行模式写作后联网，Web 端能看到；两端同时改正文会保留可找到的冲突副本。笔记本元数据 / 目录冲突应可选择，不静默覆盖本机目标。
- [ ] 笔记本新建、信息、章节 / 引用、移动 / 排序、归档恢复、引用回收恢复、解除引用和解散正常。永久删除只用专门样例，具名确认后核对结果。
- [ ] Photo Picker 选图与取消：成功上传才插入正式 URL；上传中切文档不串图。已缓存图片断网可读，未缓存图片有缺图状态。缓存满 128 MiB 后正文仍可保存，联网图片仍可使用。
- [ ] 从浏览器 / 文本应用分享文字与链接；从相册分享一张 / 多张图，断网后重启应用再联网，文字保留且附件续传。每次最多 10 张、单图最多 10 MiB；失败可在设置重试。
- [ ] 通过 SAF 导出格式 3 ZIP，再导入独立测试空间；核对空正文、回收站、正文 / 目录历史、图片和分享附件。取消选择不改数据；相同 ID 不覆盖已有正文，不同备份正文进入历史。
- [ ] ZIP 实际解压总量限 128 MiB；导出文件用完可自行备份或移除。备份不含令牌，图片与正文为明文数据。
- [ ] 打开统计跨端同步不会改变正文版本 / 修改时间。

## 系统入口与性能

- [ ] 添加 / 缩放桌面小组件，核对最近五篇和新建；深浅色桌面文字可读。切实例后刷新组件；旧组件入口应拒绝跨实例打开。
- [ ] Doze、断网恢复、前后台切换及厂商省电限制下，无重叠同步或常驻轮询；强制停止后重新打开应用才能恢复调度。记录实际延迟，不要求固定 15 分钟执行。
- [ ] 在中档真机运行 profileable 基准，各至少 10 轮：500 条元数据列表与约 2,000 字符缓存笔记，分别记录在线 / 离线、中位数 / P95、温度及 WebView。初始目标列表 P95 ≤ 1 秒，笔记可输入 P95 ≤ 2 秒。
- [ ] 真机使用 5,000 / 20,000 条数据检验分页滚动、搜索延迟、内存与帧时间；模拟器基线不作为规模上限结论。

## 正式发布前

- [ ] 完成人工门禁并记录失败项 / 限制，配置持久生产签名与受保护的 CI Secret；正式 release 禁止 WebView 调试和明文连接。
- [ ] 选择正式新版本，按根 AGENTS.md 同步包与锁文件、CHANGELOG、验证、发布提交、标签、推送、部署与 GitHub Release。内部包沿用当前根版本，不是新的正式 1.1.5 发布。

验收记录建议：设备 / 系统 / WebView / 输入法；场景；实际结果；预期；复现步骤；截图；是否仍有可读原稿。不要把系统立即杀进程时尚未持久化确认的输入记作已保存。
