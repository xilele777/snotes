# 当前 UI 规范

本文描述当前实现；变更历史见 [ui-refresh.md](ui-refresh.md)，本轮修复依据见 [UI 审阅](audits/2026-11-02-ui-consistency-review.md)。

## 尺寸与样式归属

`src/ui-tokens.css` 是公共尺寸、字级和圆角的来源。主题颜色继续集中在 `src/styles.css`，不得在页面中重新定义主题色或顶部高度。

| 范围 | 规范与实现位置 |
| --- | --- |
| 顶栏 | `--header-height`：桌面/平板 64px，≤720px 为 60px；`workspace.css` 维护三栏的共享 flex、边框盒与中心线 |
| 普通控件 | `--control-size`：桌面 36px；紧凑控件使用 `--control-compact-size` 32px |
| 触屏 | 手机视口或粗指针设备，两档控件均为 44px；图标、开关轨道与颜色圆点可保持较小的视觉大小 |
| 字级 | 页面标题 18px、标签 14px、紧凑内容 13px、辅助信息 12px；编辑正文的字号与行距仍由用户设置 |
| 间距 | 优先使用 4/8/12/16/24/32px 的 spacing 变量；图标光学修正、边框和编辑器排版允许专用值 |
| 圆角 | 控件 6px、浮层 8px、卡片 12px；圆形、胶囊和开关轨道例外 |
| 页面 | `pages.css` 负责设置/统计页面容器；`knowledge-base.css` 负责笔记本目录和卡片；不要覆盖工作区 header 的公共高度 |
| 基础控件 | `styles.css` 维护按钮、输入框、菜单、弹窗等共用外观；组件 scoped CSS 只维护组件内部内容 |

不要通过新增后加载样式修补同一组件的尺寸。先修改负责该组件的规则，响应式尺寸优先通过 token 调整。顶栏不靠独立的上下 padding 模拟居中。

## 状态与交互

- 手机编辑器格式工具栏直接显示工具，保持单行横向滚动和 44px 点击区域，不折叠为少量按钮或换行展开；滑动不得触发工具。大纲仍沿用窄编辑区隐藏规则。
- 选中项使用 `--selected-bg` / `--selected-text`；hover 使用 `--bg-hover`，按下使用 `--bg-press`。笔记本目录与普通列表保持一致，选中状态增加字重作为额外线索。
- 主要操作使用 accent 系列；危险操作使用 danger / danger-press 系列；禁用项必须保留 `disabled` 和对应外观。继续使用可见的键盘焦点描边。
- 分段单选统一用 `SegmentedControl.vue`。每组一个 Tab 入口，方向键循环切换选中项并移动焦点，Home/End 到两端，点击与键盘使用同一更新事件。
- 菜单与编辑器选择浮层共用 `ActionMenu.vue` 的 Teleport、视口限制、翻转、内部滚动、ResizeObserver、关闭与焦点归还。菜单保持 menu/menuitem；选择器保持 group/button，不混用语义。
- 浮层打开时聚焦已选或首个可用按钮；方向键与 Home/End 可导航；Esc/Tab 关闭并回到触发按钮；点击外部已获得焦点的控件时不得抢回焦点。
- 从「更多」转入选择浮层时，以更多按钮为锚点；由直接按钮打开时以直接按钮为锚点。两种入口拥有相同的选择器行为。
- 设置开关使用完整按钮作为点击区域，视觉轨道在按钮内居中。颜色按钮也将视觉圆点与点击区域分开。扩大点击区域后必须重新检查窄窗口，不允许区域重叠。
- 长名称截断并保留完整 title；低频编辑操作继续根据编辑区宽度收进更多菜单。尊重减少动态效果设置。

## 修改后的验收

检查浅色/深色、桌面三栏、收起侧栏、手机列表/编辑器、320px 最窄布局和短窗口长浮层。测量时等待过渡完成。

交互变更运行对应单元测试和浏览器测试；发布前执行 `npm run test:all`、`npm run build`，并运行完整浏览器回归。`tests/e2e/ui-consistency.spec.ts` 覆盖中心线、点击区域、短窗口浮层和设置单选键盘操作。

此规范覆盖应用自有控件；第三方编辑器内部控件及真实手机系统键盘需要独立验收，不据此宣称整站无障碍合规。
