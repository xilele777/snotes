## 界面与操作

桌面采用可调宽度的导航、笔记目录和正文三栏，支持收起侧栏及笔记列表。回收站位于侧栏底部、统计入口上方，切换后沿用相同的列表和预览尺寸。统计和设置在侧栏旁作为独立页面打开，返回后保留原来的编辑位置与撤销记录。统计热力图独占一行，窄屏可在卡片内横向浏览。

| 入口 | 操作 |
| --- | --- |
| 全部笔记 / 星标 / 分组 | 筛选笔记，点击列表条目阅读或编辑 |
| 已隐藏 | 汇总所有「不上首页信息流」的笔记（分组菜单「不上首页信息流」、笔记「⋯」菜单「不在首页信息流显示」） |
| 回收站 | 查看已删除笔记，恢复或彻底删除，详情顶栏显示还剩几天被删除；返回笔记时恢复之前的筛选与阅读位置 |
| 左侧统计图标 | 打开统计页面，支持返回工作区和系统返回 |
| 左侧图标栏底部「设置」 | 独立分页页面：**外观**（主题、列表密度、摘要显隐、字号、编辑区宽度、正文行距、表格密度，只对当前设备生效）、**数据**（导出全部、导入备份）、**快捷键**（含 Markdown 速查）、**关于**（版本、升级步骤、退出登录）；快捷键 `Ctrl / Cmd + ,` |
| 正文顶栏 | 保留分组位置、置顶和星标；宽编辑区直接显示笔记本、历史版本和字数统计，窄编辑区通过「⋯」进入。文档信息、颜色、删除、导入导出和首页可见性位于「⋯」；修改隐藏属性或分组时保持当前视图与正文 |
| 编辑器工具栏的全屏按钮 | 使用 Vditor 原生全屏编辑；再次点击按钮退出 |
| 操作提示 | 复制、下载、恢复历史等结果以顶部浮出的短消息呈现，3.5 秒自动消失；普通删除提供 5 秒「撤销」，永久删除和删除章节/整本笔记本仍需确认 |
| 正文上方的格式工具栏 | 撤销、重做、插入图片、标题、加粗、斜体、删除线、行内代码、无序/有序/待办清单、引用、代码块、链接、表格；表格先填写行数与列数（1 到 20，行数含表头，默认 3×3），再插入到光标处；光标落在某种格式里时对应按钮自动点亮 |
| 撤销与重做 | 输入后可立即点击撤销，或使用 Ctrl/⌘ Z；Ctrl/⌘ Y 或 Ctrl/⌘ Shift Z 重做，历史记录不跨笔记 |
| 正文里的链接 | 光标落到链接上时浮出气泡，可打开、编辑地址、复制、移除；Ctrl/Cmd 加点击直接新标签打开（外链带 `rel="noopener noreferrer"`） |

列表的「⋯」或右键菜单可直接置顶、星标、移至分组和删除，不必逐篇打开。

手机默认展示目录，打开笔记后进入正文；左上角按钮展开导航，返回按钮或系统返回回到列表。编辑器全屏由工具栏按钮控制。

| 快捷键 | 功能 |
| --- | --- |
| `Alt / Option + N` | 新建笔记（`Ctrl + N` 是浏览器新窗口，网页拦不住） |
| `Ctrl / Cmd + F` | 聚焦笔记搜索（编辑器外仍兼容 `Ctrl / Cmd + K`，编辑器内该键用于链接） |
| `Ctrl / Cmd + ,` | 打开设置 |
| `Ctrl / Cmd + Shift + S` / `P` | 当前笔记星标 / 置顶 |
| `Ctrl / Cmd + Alt + D` | 删除当前笔记（移入回收站并提供撤销） |
| `Ctrl / Cmd + Alt + ↑` / `↓` | 列表里切到上一条 / 下一条 |
| `Ctrl / Cmd + Alt + U` | 立即同步 |
| `Ctrl / Cmd + Z` / `Y` | 在编辑器中撤销 / 重做 |
| `Ctrl / Cmd + P` | 编辑器双栏预览 |
| `Ctrl / Cmd + '` | 编辑器全屏 / 退出全屏 |
| `Esc` | 关闭当前弹窗或侧栏，或清除搜索 |

完整清单（含编辑器内快捷键与 Markdown 速查）见设置的「快捷键」页。

## 笔记本

笔记本与外部笔记列表独立，归属笔记本的笔记不进入外部列表和统计。可从目录菜单或编辑器笔记本入口将笔记「移出笔记本，转为独立笔记」，保留正文并回到普通笔记列表。目录删除会将笔记放入回收站，恢复时保留原笔记本和章节；删除整本笔记本则是永久删除，不能通过回收站恢复。详见[笔记本使用与升级说明](knowledge-bases.md)。

## 数据备份与迁移

**应用内导出 / 导入**：图标栏「设置」的「数据」页可把全部笔记打包成 zip 下载，每个分组一个文件夹、每条笔记一个 `.md`，图片放在 `images/` 并改成相对路径，`index.json` 记录分组、星标、置顶、颜色与创建时间。同一份包可以导入回任意部署（Cloudflare 或独立服务器），图片会重新上传；重复导入不会产生副本。这是迁移和日常备份的推荐方式，不依赖命令行。

默认备份格式 3 包含本机正常笔记、全部回收站、本地正文历史及历史图片、分组、笔记本目录和快照。仅在云端的历史、尚未拉到本机的数据和无引用图片需使用服务端实例备份；Node 提供带完整性校验的实例备份与恢复工具，见运维手册。旧格式 1/2 仍可导入。导入为合并操作：先准备图片，再以一个本地事务提交笔记、分组、历史和笔记本。图片失败或本地事务中断不会留下部分笔记；同 ID 的不同正文保留到笔记历史，不覆盖现有正文。已上传图片保留并可在重试时复用；云端上传不属于本地事务，失败仍可能留下孤立对象。

单篇正文同步/导入上限为 1 MiB（UTF-8 字节数，中文通常每字占 3 字节），一次选择的文件合计不超过 100 MiB。ZIP 最多 10,000 个条目、单条解压 32 MiB、累计解压 256 MiB；超限会提示拆分。编辑超限内容不会被静默截断，同步失败任务保留在本机，可到设置 → 数据下载后拆分。

保存失败时，设置 → 数据会显示尚未落库的草稿，可重试保存或下载；原笔记已不存在时，会恢复成独立副本。同步失败任务也在此页提供错误、数据下载与重试。本地保存完成与上传云端完成是两个不同状态，退出或迁移前需确认同步。

**独立服务器 / Docker**：先让客户端同步，再停止服务并备份整个数据目录或数据卷，包括 SQLite、可能存在的 WAL/SHM 文件和图片。具体命令及恢复方法见[服务器备份、升级与恢复](server-deployment.md#备份升级与恢复)。Cloudflare 与服务器的数据不会自动互相迁移。

Cloudflare 的 D1/R2 备份与恢复见[运维手册](operations.md#每月备份)。SQL 备份不包含 R2 图片，也不包含浏览器里尚未同步的修改。

## 自动清理

服务端每天执行一次维护任务（`worker/maintenance.ts`），Cloudflare 版由 `wrangler.jsonc` 里的 `triggers.crons` 触发，独立服务器版在进程内每 24 小时执行一次：

- **图片保留**：目前暂缓永久回收，删除笔记或笔记本后仍保留已上传图片，保护跨笔记复制和长期离线重新引用。存储占用会持续累积；不要只根据当前在线设备的正文手动删除图片。
- **回收站过期清理**：默认 30 天。进入回收站超过该天数的笔记会被自动彻底删除，效果与手动「彻底删除」一致，删除信号照常同步到其他设备；回收站里每条笔记显示还剩几天。要改天数，Cloudflare 在 `wrangler.jsonc` 的 `vars` 里加 `"TRASH_RETENTION_DAYS": "7"` 后重新部署；独立服务器在 `.env.server` 或 `.env` 里设置同名变量后重启。值必须是正整数天数，`0` 或 `off` 表示关闭，非法值会让服务器拒绝启动。
- **墓碑回收**：彻底删除的笔记在数据库里保留 30 天的删除标记供其他设备同步，超期后物理删除；此前只有手动清空回收站时才回收。

Cloudflare 本地调试可用 `npx wrangler dev --test-scheduled` 启动后访问 `http://localhost:8787/__scheduled` 手动触发。

## 安装与更新

在支持的浏览器中，可将应用安装到桌面或手机主屏。PWA 安装和远程访问需要 HTTPS；localhost 可用于本地 HTTP 测试。离线能力只覆盖已下载到本机的内容及已缓存的图片。

更新提醒查询 GitHub 最新稳定版，成功结果缓存 24 小时。它不会自动升级服务端；完成服务端升级后，保持联网等待新缓存下载，再重新打开应用，并在设置的「关于」页核对版本。

## 安全与访问令牌

这是**单用户自托管**应用，鉴权模型只有一个共享令牌，请在此前提下使用：

- 拿到 `ACCESS_TOKEN` 的人可以读写你的全部笔记与图片，不提供多用户账户或协作编辑；Agent 可另用按笔记本授权的独立凭证
- 令牌保存在浏览器 `localStorage`，另有一个作用域限定为 `Path=/api/images/` 的 Cookie 专供 `<img>` 使用
- 更换令牌：Cloudflare 使用 `wrangler secret put ACCESS_TOKEN`；直接运行 Node.js 时修改 `.env.server` 或服务环境文件并重启进程；Docker 修改 `.env` 后执行 `docker compose up -d --force-recreate snotes`。使用旧令牌的客户端会收到 401 并回到输入页，本地数据不受影响
- 不要把令牌写进 `wrangler.jsonc` 或任何会进仓库的文件；服务器令牌仅保存在被忽略的环境文件或服务端密钥文件中
- 独立服务器版内置登录限流：同一来源连续 5 次令牌错误后封锁 1 分钟，封锁期满再错则时长翻倍，最长 1 小时；期间该来源的全部 `/api/` 请求返回 429，`/api/health` 不受影响。来源按 socket 地址判定，只有本机或内网反向代理带来的 `X-Forwarded-For` 才被采信，详见[服务器部署文档](server-deployment.md)
- Cloudflare 版不在代码里做限流，建议在 Cloudflare 控制台的 **Security → WAF → Rate limiting rules** 里添加规则：匹配 URI 路径以 `/api/` 开头且响应状态码为 401 的请求，同一 IP 在 1 分钟内超过 5 次即封锁 10 分钟。具体可用规则、响应状态码计数能力与额度取决于当前套餐，请以 Cloudflare 控制台和官方说明为准

发现安全问题请通过 GitHub 的 [Security Advisory](https://github.com/xilele777/snotes/security/advisories/new) 私下报告，不要开公开 issue。
