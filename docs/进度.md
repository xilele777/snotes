## 开发中发现的坑

- **两层弹窗叠加时的 Esc**：设置弹窗和它上面的退出确认框都用 `useDialogFocus`，两个 `keydown` 监听都在捕获阶段，Esc 会把两层一起关掉。改为每个实例先看 `document.querySelectorAll('[aria-modal="true"]')` 的最后一个是不是自己，不是就不处理；确认框 Teleport 到 body 末尾保证它在文档顺序上靠后。
- **`history.length` 在 jsdom 里不可靠**：前面用例的 `history.back()` 会截断栈，后续 `pushState` 不一定让 length 加一。断言「有没有多压一层」改为 `vi.spyOn(history, 'pushState')` 数调用次数。
- **popstate 防重入**：`onPopState` 用微任务窗口去重，同一同步块里连派两次 `PopStateEvent` 第二次会被吞掉；测试里要 `await Promise.resolve()` 再派。
- **Git Bash heredoc**：内容里带单引号的 `cat <<'EOF'` 和 `python - <<'PY'` 会在长脚本上截断报 `unexpected EOF`，改成用 Write 工具把补丁脚本写到 `tmp/*.py` 再执行。
- **单测里不能对 Dexie 用 `vi.useFakeTimers()`**（沿用 0.13.0 的经验）：`notify.test.ts` 可以用 fake timers，因为它不碰数据库。
