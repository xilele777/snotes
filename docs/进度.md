## 开发中发现的坑

- **单测里不能对 Dexie 用 `vi.useFakeTimers()`**：fake-indexeddb 靠 `setTimeout` 推进事务，冻住后事务永不结束，用例超时且后续 `beforeEach` 的 `db.delete()` 也一起卡死。需要推时间时只 `vi.spyOn(Date, 'now')`，用完 `vi.restoreAllMocks()`。
- **快照时间用旧正文的 `update_time`**，不是「现在」。列表里显示的是「这一版是什么时候写的」，用现在的时间会让所有快照看起来都是「刚刚」。
- **恢复时的当前正文要无条件存**，不走 5 分钟 / 100 字阈值：用户点恢复是明确动作，此刻正文一旦被覆盖没有其他去处。
- **多行 Bash heredoc 里嵌 Python 再嵌 TS 模板字符串会被 shell 提前吃掉引号**，整条命令一个字节都不执行。改用 Write/Edit 工具逐文件写，或把 Python 脚本先写成文件再执行。
- 沿用上次：跑 E2E 前 `unset HTTP_PROXY HTTPS_PROXY`；E2E 全量约 4.5 分钟；Playwright 的 wrangler webServer 偶发 120 秒超时重跑即可。
- **未跟踪文件**：`pelican-cycling.html`、`shot.tmp.mjs` 不是本项工作的产物，没有纳入任何提交。
