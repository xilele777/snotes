# 界面设计与本地验收

当前界面参考[滴答清单网页端](https://dida365.com/webapp/#q/all/tasks)的窄图标栏、白色分区、紧凑列表与浅灰选中态，结合笔记应用的阅读和编辑需求调整布局。

## 布局与交互

- 桌面导航由 52px 图标栏和分组栏组成，图标栏提供笔记与统计入口。1440px 屏幕下，导航、目录、编辑区分别为 248px、352px、840px。
- 回收站位于“星标笔记”下方。切换时保留完整侧栏，目录和预览尺寸与普通笔记一致；回收站复用笔记条目和详情组件，正文为只读，操作替换为恢复和彻底删除。
- 统计使用最大 1120px 宽的大弹窗，背景工作区保持原有布局、编辑器实例和撤销记录。手机上保留边距和关闭按钮，图表按弹窗宽度排列并在内部滚动；关闭按钮、遮罩、Esc 和系统返回均可关闭。
- 从回收站返回笔记时恢复此前分组、搜索、选中笔记和滚动位置；浏览器导航也记录这些状态。只保存位置数据，不缓存额外的列表或编辑器实例。
- 分组和笔记选中时使用浅灰底，正文保持深灰。蓝色用于新建、星标、焦点和图表；强调色为 `#4668e8`。
- 目录行高从 104px 收紧到 90px，保留标题、摘要、日期、分组与标记。缩略图改用 CSS Grid 排列，图片声明尺寸并延迟加载。
- 编辑区统一使用共享线条图标。左上角分组名称同时是移动分组的入口，减少重复操作；常用工具、专注模式和底部文档信息保持直接可用。
- 弹窗、回收站和统计页使用相同的颜色、分隔线和圆角。字数弹窗的关闭按钮居中，回收站保持单一空态，统计页保持精简布局。
- 1020px 以下使用导航抽屉，720px 以下在目录与正文间切换。手机图标栏显示文字标签，搜索直接位于目录上方。
- 抽屉打开时立即变为可见，以便接收键盘焦点；关闭时延迟隐藏，保留滑出过渡。Esc 关闭后焦点返回触发按钮。

图标栏和分组栏共用 `GroupSidebar.vue` 与现有导航状态。`StatsDialog.vue` 提供弹窗外壳，统计内容和 `insights.css` 仍按需加载；滚动恢复集中在 `useWorkspaceScroll.ts`。使用系统字体、内联 SVG 和 CSS 动画，没有新增运行时依赖。

## 应用图标

`public/snotes.svg` 是应用标识的唯一设计源文件：蓝色圆角底、白色折角便签。侧栏、登录页和浏览器 SVG 图标直接引用它；PNG 图标由同一文件生成，避免不同入口的图案不一致。

修改 SVG 后运行 `npm run icons:generate`，并提交生成的 PNG。首次运行需要 `npx playwright install chromium`；生成器复用项目已有的 Playwright，日常构建无需启动浏览器。

- `favicon-32.png`：浏览器图标的 PNG 回退。
- `apple-touch-icon.png`：180px、不透明背景，供 iOS 添加到主屏幕。
- `snotes-192.png` / `snotes-512.png`：普通 PWA 图标。
- `snotes-maskable-512.png`：不透明背景，供 Android 等平台按系统形状裁切；便签图案保留在中心直径 80% 的安全圆内。

这些资源均进入 PWA 预缓存，离线时可用。新图标使用新的资源地址，便于浏览器更新旧的纯色占位图标；已安装应用的桌面图标更新时间由浏览器和系统决定。

## 加载体积

与已发布的 v0.6.1 产物比较，使用同一 Node.js gzip 方法测量，单位为十进制 KB：

| 产物 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 入口 JavaScript | 230.65 KB | 231.96 KB |
| 入口 CSS | 28.25 KB | 30.81 KB |
| 入口 JavaScript + CSS（gzip） | 85.89 KB | 86.63 KB |

编辑器、统计页及统计样式继续按需加载。390px、320px 的独立浏览器上下文确认：手机目录首屏只执行入口脚本与 Service Worker 注册脚本，打开笔记后才加载编辑器。

与 v0.6.1 相比，入口压缩体积增加约 0.74 KB。浏览器检查禁用 Service Worker，避免缓存影响首屏模块检查；正常构建保留 PWA 预缓存和离线能力。

## 本地预览

预览地址：<http://127.0.0.1:8788>，测试令牌为 `dev-token`。

预览使用独立的 `tmp/dida-ui-preview-state`，初始样例为七条笔记、三个分组及一条回收站笔记，后续操作保留在本地数据中。启动命令：

```bash
npm run build
npx wrangler d1 migrations apply snotes-e2e --local --config tests/e2e/wrangler.jsonc --persist-to tmp/dida-ui-preview-state
npx wrangler dev --local --config tests/e2e/wrangler.jsonc --persist-to tmp/dida-ui-preview-state --port 8788 --ip 127.0.0.1 --inspector-port 0
```

本机 `tmp/dida-ui-review/` 保存参考截图、调整前后截图、手机与平板截图、构建体积及浏览器检查报告。`seed-preview.mjs` 仅用于向空的本地预览库添加样例；`review-continuity.mjs` 检查当前弹窗和分栏，并保留预览库里的用户操作。

- 23 项端到端测试通过，覆盖编辑、保存、搜索、分组、图片、同步、回收站、专注模式、清单和手机操作。
- 有序列表的空起点、显式 0、嵌套非 1 起点在粘贴、保存和刷新后保留正确编号。
- 新增图标栏返回笔记的回归验证，并补充抽屉焦点恢复及 320px 分组浮层边界验证。
- 统计打开和关闭时编辑器实例、撤销、筛选与滚动保持不变；榜单链接打开目标笔记，返回后恢复原分组；手机系统返回关闭统计后，焦点回到可见导航入口。
- 回收站入口顺序、侧栏与目录尺寸、预览位置均有回归验证；返回普通笔记后还原选中项和两栏滚动。

- 桌面和手机字数弹窗的关闭按钮中心偏差为 0，独立浏览器检查未发现页面异常。
- 生产构建及类型检查通过。
