## CI 提速

本次起 Verify 工作流：Playwright 浏览器二进制按 lockfile 缓存（省去每次每 job ~150MB 下载），e2e 按后端 × 2 分片并行（片内保持串行、各自全新 webServer 与本地 D1）。全量 run 从 v1.0.2 的 14m42s 降到 **5m45s**。

本次线上核验未创建或修改生产数据。性能改进属于客户端行为：一次性 v4 迁移后，列表加载与同步刷新不再随笔记总量线性变慢（2000 条笔记热启动列表 -30%）。
